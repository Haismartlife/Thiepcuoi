CÁCH THÊM NHẠC NỀN:

1. Chuẩn bị file nhạc định dạng .mp3, đặt tên: nhac-nen.mp3
   (chọn nhạc không lời, dung lượng nhỏ, khoảng 2-4 phút là đủ vì sẽ tự lặp lại)
2. Thả file vào đúng thư mục này (assets/audio/)
3. File index.html đã có sẵn thẻ <audio src="assets/audio/nhac-nen.mp3">
   — không cần sửa gì thêm, chỉ cần đúng tên file là chạy được.

LƯU Ý BẢN QUYỀN:
Nếu dùng nhạc có bản quyền (nhạc phim, nhạc thị trường...), nên xin phép/mua bản quyền
nếu thiệp được chia sẻ công khai. Một số nguồn nhạc nền miễn phí/không bản quyền
để tham khảo: Pixabay Music (pixabay.com/music), Free Music Archive, YouTube Audio Library.
